# 🐯 ผจญภัยแนวคิดเชิงคำนวณกับพี่เสือ

เกมเว็บสำหรับฝึกทักษะแนวคิดเชิงคำนวณ (Computational Thinking) 4 ด่าน มีระบบเก็บสถิติการเล่น
และแบบประเมินความพึงพอใจอยู่ในระบบเดียวกัน ใช้ **Netlify** เป็นเว็บโฮสต์ และ **Turso** เป็นฐานข้อมูล

## สิ่งที่มีในชุดนี้

| หน้า | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าแรก ให้นักเรียนกรอกชื่อ ห้อง และเลขที่ |
| `game.html` | ตัวเกม 4 ด่าน รวม 16 ข้อ (160 คะแนน) |
| `survey.html` | แบบประเมินความพึงพอใจแบบมาตราส่วน 5 ระดับ จำนวน 10 ข้อ และช่องข้อเสนอแนะ |
| `dashboard.html` | แดชบอร์ดสำหรับครู (ต้องใส่รหัสผ่าน) แสดงสถิติ กราฟ ค่า x̄ / S.D. พร้อมการแปลผล และปุ่มดาวน์โหลด CSV |

**ด่านในเกม**
1. 🧩 การแยกย่อยปัญหา (Decomposition) — จัดงานย่อยเข้าหมวดหมู่ 3 ข้อ
2. 🔍 การจดจำรูปแบบ (Pattern Recognition) — หาตัวถัดไปของลำดับ 6 ข้อ
3. 🎯 การคิดเชิงนามธรรม (Abstraction) — เลือกเฉพาะข้อมูลที่จำเป็น 4 ข้อ
4. 🧭 การออกแบบอัลกอริทึม (Algorithm) — เขียนบล็อกคำสั่งพาพี่เสือผ่านเขาวงกต 3 ภารกิจ

## ขั้นตอนนำขึ้นใช้งาน

### 1) สร้างฐานข้อมูล Turso
1. สมัครหรือเข้าสู่ระบบที่ https://turso.tech แล้วกด **Create Database** (เลือก Location ที่ใกล้ที่สุด เช่น Singapore / Tokyo)
2. เข้าไปที่ฐานข้อมูลที่สร้าง แล้วคัดลอก **Database URL** (ขึ้นต้นด้วย `libsql://...`)
3. กด **Create Token** แล้วคัดลอก **Auth Token** เก็บไว้

> ไม่ต้องสร้างตารางเอง ระบบจะสร้างตารางให้อัตโนมัติเมื่อมีการใช้งานครั้งแรก

### 2) นำขึ้น Netlify
Netlify ต้องติดตั้งไลบรารี `@libsql/client` ตอน build จึงต้อง deploy ผ่าน GitHub หรือ Netlify CLI
(ถ้าลากโฟลเดอร์ไปวางในหน้าเว็บ Netlify ระบบ API จะใช้งานไม่ได้)

**วิธี A — ผ่าน GitHub (แนะนำ)**
1. อัปโหลดทั้งโฟลเดอร์นี้ขึ้น GitHub repository
2. ที่ Netlify กด **Add new site → Import an existing project** แล้วเลือก repository นั้น
3. ระบบจะอ่านค่าจาก `netlify.toml` ให้อัตโนมัติ (Publish directory = `public`) แล้วกด Deploy ได้เลย

**วิธี B — ผ่าน Netlify CLI**
```bash
npm install
npx netlify-cli login
npx netlify-cli deploy --build --prod
```

### 3) ตั้งค่า Environment variables
ที่ Netlify ไปที่ **Site configuration → Environment variables** แล้วเพิ่ม 3 ค่านี้

| ชื่อ | ค่า |
|---|---|
| `TURSO_DATABASE_URL` | Database URL จาก Turso (`libsql://...`) |
| `TURSO_AUTH_TOKEN` | Auth Token จาก Turso |
| `ADMIN_KEY` | รหัสผ่านสำหรับเข้าแดชบอร์ดครู (ตั้งเองให้เดายาก) |

จากนั้นกด **Deploys → Trigger deploy** อีก 1 ครั้งเพื่อให้ค่าที่ตั้งไว้มีผล

### 4) ตรวจสอบการเชื่อมต่อ
เปิด `https://ชื่อเว็บของคุณ.netlify.app/api/health` ถ้าขึ้น `{"ok":true,"database":"connected",...}` แสดงว่าเชื่อมต่อฐานข้อมูลสำเร็จ

## การปรับแต่ง

- **แก้ไข/เพิ่มโจทย์** ทำได้ในไฟล์ `public/assets/data.js` ไฟล์เดียว (มีคำอธิบายในไฟล์)
  - เขาวงกต: `S` = จุดเริ่ม, `G` = เป้าหมาย, `#` = ต้นไม้, `.` = ทางเดิน และ `maxBlocks` คือจำนวนบล็อกสูงสุดที่ใช้ได้
  - แบบประเมินต้องมี **10 ข้อพอดี** เพราะตรงกับคอลัมน์ `q1`–`q10` ในฐานข้อมูล
- **เปลี่ยนรูปพี่เสือ** ให้แทนที่ไฟล์ `public/assets/tiger.svg` ด้วยรูปของคุณโดยใช้ชื่อไฟล์เดิม
  (ถ้าเป็นไฟล์ PNG ให้แก้ `tiger.svg` เป็น `tiger.png` ในไฟล์ HTML และ `game.js`)
- **สีของธีม** แก้ได้ที่ตัวแปรช่วงบนของ `public/assets/style.css`

## การคิดคะแนน

| ด่าน | วิธีคิด (ข้อละ 10 คะแนน) |
|---|---|
| แยกย่อยปัญหา | คิดตามสัดส่วนงานที่จัดเข้าหมวดถูก |
| จดจำรูปแบบ | ตอบถูกได้ 10 คะแนน ตอบผิดได้ 0 คะแนน |
| คิดเชิงนามธรรม | (จำนวนข้อที่เลือกถูก − จำนวนข้อที่เลือกผิด) ÷ จำนวนข้อที่ควรเลือก × 10 |
| อัลกอริทึม | ผ่านในการรันครั้งแรกได้ 10 คะแนน หักครั้งละ 2 คะแนน (ต่ำสุด 4 คะแนน) และกดข้ามได้หลังรันไม่ผ่าน 3 ครั้ง |

**เกณฑ์การแปลผลความพึงพอใจ:** 4.51–5.00 มากที่สุด · 3.51–4.50 มาก · 2.51–3.50 ปานกลาง · 1.51–2.50 น้อย · 1.00–1.50 น้อยที่สุด
(ค่า S.D. ใช้สูตรของกลุ่มตัวอย่าง n − 1)

## โครงสร้างฐานข้อมูล

- `game_sessions` — การเล่น 1 รอบ: ชื่อ ห้อง เลขที่ คะแนนรวม ร้อยละ เวลาที่ใช้ และวันเวลา (เวลาไทย)
- `stage_results` — คะแนนรายด่านของแต่ละรอบ: คะแนน ข้อที่ถูกสมบูรณ์ จำนวนครั้งที่ตอบ/รัน และเวลา
- `surveys` — แบบประเมิน: คะแนน q1–q10 ข้อเสนอแนะ และ `session_id` ที่เชื่อมกับรอบการเล่นล่าสุด

## หมายเหตุ
- ถ้าอินเทอร์เน็ตหลุดตอนส่งผล ระบบจะเก็บข้อมูลไว้ในเบราว์เซอร์ และส่งให้อัตโนมัติเมื่อเปิดเว็บครั้งถัดไป
- ข้อมูลที่แสดงในแดชบอร์ดจำกัดไว้ที่ 3,000 รายการล่าสุด
